# 模型路由与缓存收益多轮基准（2026-08-31）

方法：真实线上栈（OpenCode Go 通道），统计报表页成本面板同源计价
（`PROCUREMENT_MODEL_PRICING` 官方定价 × runtime_event 实测 token，缓存折扣同 Python `_cost_usd` 口径）。
每任务 = 需求结构化 + 双报价解析的完整 capture run；`/api/procurement/operations`
轮询到 completed 计端到端墙钟（300ms 粒度）；远端轮次/ token 按 `model_turn_end` 事件的
model ∈ 远程模型集合统计；全部指标可经 `/api/runs/{id}` 复算。

## A 组：缓存前置路由（8 对冷热对照，同消息两次执行）

| 指标 | 冷（中位） | 热（中位） | 变化 |
|---|---:|---:|---:|
| 远端模型轮次 | 3 | 0 | **-100%（8/8 全命中）** |
| 远端 token | 5,034 | 0 | -100% |
| 成本 | $0.00040 | $0.00000 | -100% |
| 端到端延迟 | 33,374ms | 692ms | **-97.9%** |

注：冷路径为阶梯第一档（mimo-v2.5）；热路径 run 创建前即路由确定性工具图，
capture 工具从语义缓存取回已通过校验的需求，全程零远程调用。

## B 组：阶梯路由开关对照（各 8 任务，全新消息避免缓存干扰）

| 指标 | B1 阶梯开（mimo 档） | B2 阶梯关（hy3 主模型） | 变化 |
|---|---:|---:|---:|
| 成本中位 | $0.000441 | $0.000732 | **-39.7%** |
| 总成本（8 任务） | $0.003575 | $0.006109 | -41.5% |
| 远端 token 中位 | 5,522 | 4,862 | +13.6%（mimo 更啰嗦） |
| 端到端延迟中位 | 27,968ms | 19,249ms | +45%（**以时换钱**，如实记录） |

## 结论（可写进简历的口径）

- 重复输入：远端调用 3→0 轮、端到端 -97.9%（n=8 对，全命中）
- 解析类降档阶梯：capture 步骤成本 -39.7%（n=8×8，官方定价折算，代价 +45% 延迟）
- 单项路由收益与缓存收益正交叠加：首次输入省 40%，重复输入省 100%

## 局限（面试如实说）

- 单任务规模（demo 数据），美元绝对值小，收益以比例表述
- 延迟含 300ms 轮询粒度与网络抖动；成本为列表价折算，Go 订阅实际为配额计费口径
- mimo 输出 token 多 13.6%：便宜档的"话痨税"已计入，-39.7% 是净收益
- 阶梯升档链在真实流量中未触发（mimo 8/8 一次通过）；升档正确性由单元/集成测试背书

复现：`node bench.tmp.mjs A|B1|B3 <salt>`（B3 前经模型配置文件覆盖关闭 light_model）。
